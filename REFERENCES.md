# References & Credits

EvalForge's methodology is based on:

- **Hamel Husain & Shreya Shankar** — *"Frequently Asked Questions (And Answers) About AI Evals"* (2025).
  The source of the core principles this tool aims to operationalize: **error-analysis first**, **binary pass/fail** evaluators over Likert scales, **app-type-specific** strategies, and a **cost hierarchy** for evaluators (cheap assertions/regex before LLM-as-judge).

This repository does **not** redistribute that document. Please obtain it directly from the authors.

All generated evaluators and synthetic test data are produced at runtime from the user's own code and inputs.
